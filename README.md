# 🧠 Neuracore — Enterprise AI & Analytics Landing Page

> A modern, high-performance, and visually engaging landing page for an Enterprise Artificial Intelligence platform. Built with semantic HTML5, custom CSS3 animations, Tailwind CSS, and powered by GSAP for fluid motion design.

## 🌟 Overview

**Neuracore** is a conceptual SaaS platform designed to showcase production-grade AI solutions for enterprise-level applications—spanning Predictive Analytics, Natural Language Processing (LLM), Computer Vision, and Intelligent Automation. 

This project demonstrates clean web architecture, responsive design principles, and modern micro-interactions using scroll-triggered animations.

---

## 🚀 Key Features

- **⚡ High-Performance Animations:** Powered by **GSAP (GreenSock)** and **ScrollTrigger** for smooth entrance effects, staggered reveals, and interactive counters.
- **🎨 Dark Mode First:** Designed with a sleek, futuristic dark-themed palette (`#09090B`) featuring custom neon glowing gradients and subtle mesh grid overlays.
- **📱 Fully Responsive:** Seamlessly adapts across mobile, tablet, and desktop viewports using Tailwind CSS utility classes.
- **🧩 Clean Codebase:** Modular directory structure separating HTML structure, custom CSS styles, and JavaScript interactions.
- **⚡ Fast Load Times:** Lightweight assets with zero heavy bundler overhead.

---

## 🛠️ Tech Stack & Libraries

| Technology | Purpose |
| :--- | :--- |
| **HTML5** | Semantic structure and SEO-friendly document outline |
| **Tailwind CSS** | Utility-first framework for rapid styling and layouts |
| **CSS3** | Custom keyframe animations, masking, and CSS variables |
| **GSAP 3.x** | Core animation engine for smooth scroll-driven reveals |
| **GSAP ScrollTrigger** | Scroll-based interaction and numeric counter triggers |
| **Google Fonts** | *Space Grotesk* (Headings) & *Inter* (Body typography) |
